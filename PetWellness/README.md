# PetWellness

PetWellness is a web application for pet owners and veterinary staff.

## Features

### Owner Side
- Create account and log in
- Add pet profiles
- View pets
- View pet history
- Schedule appointments
- View appointments

### Hospital Side
- Manage staff accounts
- Create visit records
- View patient history
- Add procedures and treatments
- View procedures for a visit
- Manage appointments
- View all appointments
- Manage inventory
- View inventory reports
- Record technician notes and vitals
- View hospital reports and KPIs

## Tech Stack
- Java
- JSP
- MySQL
- Apache Tomcat
- HTML/CSS
